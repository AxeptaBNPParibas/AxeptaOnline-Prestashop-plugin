## Overview

The Axepta Online module for PrestaShop enables merchants to process secure online payments through Axepta BNP Paribas.

## 💳 Supported Payment Methods

- CB
- Visa
- Mastercard
- American Express
- Apple Pay (on checkout page)
- Google Pay (on checkout page)
- PayPal

## ⚙️ Features

- Automatic capture
- Manual capture
- Iframe
- Recurring payment
- One-click payment
- 3DS exemption request
- Installment payment (non-guaranteed)

## 📦 Installation

### Method 1 — PrestaShop Back-office

1. Go to **Modules > Module Manager**
2. Click **Upload a module**
3. Upload the ZIP
4. Follow the on-screen instructions

### Method 2 — Manual Installation

1. Extract the ZIP
2. Copy the folder to `/modules/`
3. Install the module from the **Module Manager**

## Présentation

Le module Axepta Online pour PrestaShop permet aux marchands d'accepter des paiements sécurisés en ligne via Axepta BNP Paribas.
Il s'intègre de manière fluide et prend en charge un ensemble complet de moyens de paiement.

## 💳 Moyens de paiement

- CB
- Visa
- Mastercard
- American Express
- Apple Pay (intégré sur la page de paiement)
- Google Pay (intégré sur la page de paiement)
- PayPal

## ⚙️ Fonctionnalités

- Capture **automatique**
- Capture **manuelle**
- Iframe
- Paiements récurrents
- Paiement en un clic (One Click)
- Demande d'exemption 3DS
- Paiement en plusieurs fois non garanti

## 📦 Installation

### Méthode 1 — Back-office PrestaShop

1. Aller dans **Modules > Module Manager**
2. Cliquer sur **Upload a module**
3. Importer le fichier ZIP
4. Suivre les instructions à l'écran

### Méthode 2 — Installation manuelle

1. Dézipper l'archive
2. Copier le dossier dans `/modules/`
3. Installer le module via le **Module Manager**
